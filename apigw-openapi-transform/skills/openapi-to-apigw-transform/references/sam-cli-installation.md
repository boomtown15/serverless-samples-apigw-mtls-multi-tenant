# AWS SAM CLI Installation

The SAM CLI is required for deploying API Gateway stacks generated by the `openapi-to-apigw` tool.

**Official docs**: https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/install-sam-cli.html

## Prerequisites

- AWS CLI v2 installed and configured with credentials
- AWS account with appropriate permissions

## Linux (x86_64)

```bash
curl -Lo aws-sam-cli-linux-x86_64.zip https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-linux-x86_64.zip
unzip aws-sam-cli-linux-x86_64.zip -d sam-installation
sudo ./sam-installation/install
sam --version
```

## Linux (arm64)

```bash
curl -Lo aws-sam-cli-linux-arm64.zip https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-linux-arm64.zip
unzip aws-sam-cli-linux-arm64.zip -d sam-installation
sudo ./sam-installation/install
sam --version
```

## macOS

Download the package installer for your architecture:

- **Intel (x86_64)**: https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-macos-x86_64.pkg
- **Apple Silicon (arm64)**: https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-macos-arm64.pkg

Run the `.pkg` installer, then verify:

```bash
sam --version
```

If `sam` is not found after installation, create a symlink:

```bash
sudo ln -s /usr/local/aws-sam-cli/sam /usr/local/bin/sam
```

## Windows

Download the MSI installer from https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-windows-x86_64.msi and run it.

Then verify in a new terminal:

```cmd
sam --version
```

## Verification

A successful installation outputs:

```
SAM CLI, version X.Y.Z
```
